# AI-recommendation-app
AI recommendation app based on user preference analysis.

---

# AI 추천 앱 실행 방법

## 1. 사전 준비

### Node.js 설치
Node.js LTS 버전을 설치합니다.

### Expo Go 설치
스마트폰에 Expo Go 앱을 설치합니다.

- Android: Expo Go
- iPhone: Expo Go

---

## 2. 프로젝트 다운로드

GitHub 저장소를 다운로드하거나 클론합니다.

```bash
git clone [GitHub 저장소 주소]
```

또는 ZIP 파일로 다운로드 후 압축 해제합니다.

---

## 3. 프론트엔드 실행

터미널을 열고 `frontend` 폴더로 이동합니다.

```bash
cd frontend
```

### 패키지 설치

```bash
npm install
```

### Expo 실행

```bash
npm start
```

또는

```bash
npx expo start
```

---

## 4. 앱 실행

터미널에 QR 코드가 나타나면

1. 스마트폰에서 Expo Go 실행
2. QR 코드 스캔
3. 앱 자동 실행

---

## 5. 로그인 및 테스트

앱이 실행되면 다음 기능을 확인합니다.

- 회원가입
- 로그인
- 홈 화면 추천 확인
- 지도 화면 추천 확인
- 좋아요/싫어요 기능 확인

---

## 참고사항

- 백엔드 서버는 Render에 배포되어 있으므로 별도의 서버 실행이 필요하지 않습니다.
- 인터넷 연결만 되어 있으면 정상적으로 동작합니다.
- 처음 접속 시 Render 무료 서버가 깨어나는 데 30~60초 정도 소요될 수 있습니다.
- 로그인 또는 추천 기능이 바로 응답하지 않을 경우 잠시 기다린 후 다시 시도해 주시기 바랍니다.
